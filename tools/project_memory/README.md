This directory contains an unchanged copy of the project memory adapter from
[adaptive-agent-memory-research](https://github.com/krapcys1-maker/adaptive-agent-memory-research),
commit `255d6c7f99f2f966b13e66de120c20b887a2eb9a`.

Run the MCP server from the repository root:

```console
python tools/project_memory/server.py --root .
```

The server uses Python's standard library. It requires no package installation.
The Codex configuration uses the session's working directory as the project root.
