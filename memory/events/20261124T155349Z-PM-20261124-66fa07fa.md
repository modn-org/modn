On 2026-11-24 the human chose cascade layers plus a tighter checker for the protected install review and approval prompt. The desktop declares '@layer app, theme, protected;'. The loader wraps theme CSS in '@layer theme'. The safety properties of protected hooks are literals in ui/css/protected.css (eb5184b). The checker rejects var() in layout, visibility and size properties (forbidden-var) and refuses size, line-height, space and disabled-opacity tokens outside literal ranges (token-out-of-range), on every selector (b469b15). Protected hooks may not set font-family. Rules that name a stable data attribute found inside a protected region, or a context hook (an ancestor or sibling such as .modn-app or .modn-recent__menu), may declare only colours and fonts (b2f5360). The ignored test known_gap_root_tokens_can_shrink_protected_content is now root_size_tokens_cannot_shrink_protected_content and passes.
