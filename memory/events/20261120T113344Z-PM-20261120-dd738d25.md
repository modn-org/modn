The Windows CI test a_stalled_fetch_ends_the_grandchild_before_it_returns kept failing in rounds 4 and 5 because it depended on how fast a stub process started. Round 6 removed that test together with the process-tree kill it covered. Stall tests now use a real stalled local TCP listener and assert only the timeout class and the fallback result. They assert no pid and no grandchild. This was true at commit a93e2a4.
