As of 2026-11-13 with FigCraft 0.17.0: a parent field with {"$ref": "<as>", "field": "id"} works in node.create and instance.create in a figcraft-cli run script (reproduced with a five-step script, exit 0). as aliases are document-wide, so prefix them per frame. A new frame starts fixed at 100 by 100 px, so set hug or fill. effect.add needs type inside effect. edit.duplicate returns ids and map, no top-level id. A frame variable-mode override reaches its descendants. Child tasks on design.figcraft must run one after another because the file is binary.
