On 2026-11-20 `.gitattributes` marks `examples/themes/**` as `text eol=lf` and its `.png` and `.woff2` files as `binary`. A theme digest is BLAKE3 over file bytes, so a CRLF checkout on Windows would change it. A bucket that publishes themes must set the same rules; `docs/themes.md` says so.
