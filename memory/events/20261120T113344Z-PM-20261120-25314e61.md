A human decided on pull request 185, in round 6, to remove the custom Git fetch process-tree kill. The removal covers the fetch registry, the process-group kill, the Unix signal-hook thread and their tests. Every Modn Git fetch and clone now passes http.lowSpeedLimit and http.lowSpeedTime. Git and libcurl abort a stalled HTTP or HTTPS transfer on their own, and Modn classifies the abort as a timeout so ordered fallback moves to the next source or mirror. Hard process-tree stop and Ctrl-C forwarding are tracked in issue 190. This was true at commit a93e2a4.
