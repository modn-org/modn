On 2026-11-09 the owner replaced one design file per page with a single file, design/design.figcraft, that holds one page per desktop screen. The owner owns its design system: the variables, the text styles, and the Foundations and Components pages. The agent edits screen pages on request and changes the design system only when the owner asks in that conversation. Variables and components are local to the file, so no library publish, link or update step remains, and a design-system change reaches every screen at once. The agent drives the owner's running FigCraft app through figcraft-cli mcp --attach, and stops and asks when a request conflicts with the design system. Git can neither diff nor merge .figcraft files, so one branch at a time may change the file and the PNG renders are the reviewable change. On 2026-11-09 the owner chose two fonts: Marcellus, which has only a Regular weight, for the display and heading-l styles through modn/font/heading, and Manrope for every other style through modn/font/body. Smaller headings stay in Manrope so weights carry their hierarchy, and a theme can change either variable through the --modn-font-heading and --modn-font-body properties of #142. Tokens named modn/<group>/<name> export as var(--modn-<group>-<name>).
