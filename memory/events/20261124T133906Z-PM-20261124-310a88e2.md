The archive, catalog, and stack install previews all pass explicit executable approvals. Journey 12 approval-content-root of the desktop verifier covers the executable ask on the content-root Balatro fixture; journeys 7 and 12 passed with 159 assertions on 771ce05. Approval matching compares the destination string only and ignores the root (crates/modn-core/src/planning.rs:105); the preview still reports the root.
