On 2026-11-05 the maintainer approved the Balatro design for issue #52. Balatro mods load from %APPDATA%\Balatro\Mods, outside the game root, so Modn 0.3.0 can only detect Balatro. The core changes first: a module-declared content_root in module.json (resolved and validated in Rust), ownership schema v3 with installation roots, module API v2, root-labelled scan and doctor results, and single-component destinations with property tests. Lovely, a native injector (winmm.dll beside Balatro.exe), is managed only with an explicit opt-in flag; otherwise Modn only detects it. Steamodded is a user prerequisite in v1. v1 is Windows-only. Adopting a pre-existing Mods folder needs an acknowledgement, and --force replaces only Modn-owned files.
