ownership_key uses per-character lowercase on Windows and exact paths elsewhere. The shared migration skips updates for exact managed-file, managed-directory and created-directory keys. Non-Windows regression tests retain case-distinct records and compare database bytes across reopens. Windows folding migration tests are Windows-only. Linux runtime verification remains required.
