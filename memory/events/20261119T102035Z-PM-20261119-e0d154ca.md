With the verification feature, nothing in modn-desktop calls clipboard-win, because the file sink replaces the system clipboard write. Cargo 1.100 sets the lint cargo::unused_dependencies to warn by default. Every build with that feature, the verifier build included, prints the manifest warning unused dependency clipboard-win. Clippy with -D warnings still exits 0, because that flag does not cover Cargo manifest lints. A cfg cannot remove a dependency in the absence of a feature, so the warning stays until the project allows the lint or the crate gets a second use of clipboard-win. Decide this when the lint appears in CI output.
