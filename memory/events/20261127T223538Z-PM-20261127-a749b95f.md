The workspace sets unsafe_code = forbid. Job-object FFI needs unsafe, so crates/modn-core/Cargo.toml sets its own lint table with unsafe_code = deny, and crates/modn-core/src/acquisition/git/tree/windows.rs opts in with #![expect(unsafe_code, reason = ...)]. Every other module stays safe, and the CLI crate keeps forbid. This was true at commit 7347837. A reviewer should check that every unsafe block there carries a SAFETY comment.
