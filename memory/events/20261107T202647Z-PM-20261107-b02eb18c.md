On 2026-11-07 the user chose the signing scheme for issue #90. Each main bucket release ZIP gets a detached minisign (Ed25519) signature. Modn ships the trusted public key and accepts a key-rotation list that a trusted key signs. Modn verifies offline in Rust. The user holds the private key as a CI secret in the bucket repository. Third-party Git catalogs registered with 'modn bucket sync' pin a signer public key. Modn verifies that the synced revision's commit or tag carries a valid signature by that key. Modn refuses an unsigned or invalid revision unless the user passes an explicit --allow-unsigned flag. Modn records that opt-out and shows it in list and doctor output. Rejected: Sigstore keyless (needs a TUF root and Rekor data) and GitHub attestations (needs the GitHub API, fails offline).
