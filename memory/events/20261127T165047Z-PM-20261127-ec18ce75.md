Implemented 2026-11-27 (merges bbd63f2, e78d8b4). main may carry an optional root known-buckets.json (schema_version 1, buckets map of kind git or zip, https source, optional revision for git, fingerprint, description) that main's catalog signature covers because the digest covers every root file except catalog.sig and catalog.pub. modn bucket known lists it from the local main copy. modn bucket sync <known-name> without --source resolves an unregistered known name and compares the fetched catalog.pub key ID with the listed fingerprint before anything is written; a mismatch is BUCKET_FINGERPRINT_MISMATCH. Module trust stays explicit through bucket trust-modules. Tests reach an https source through the test-known-source-redirect feature, enabled only by modn-cli dev-dependencies.
