As of 3e5e697 (2026-11-27), the official `main` bucket copy follows `--state-dir`. Commands, core tests and CLI tests that select a profile must seed `main` at `<state-dir>/buckets/main`; `apps/modn-cli/tests/support/main_bucket.rs` provides `seed_state` and `seed_state_minimal`. Tests that resolve app data must still redirect `LOCALAPPDATA`, `APPDATA` and `MODN_APPDATA` to temporary directories. A test that creates a profile to prove a command writes no manager state may now find the seeded `buckets/main` there, so assert on `state.sqlite` or the registry instead of the whole directory.
