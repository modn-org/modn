Implemented 2026-11-14 on the Milestone 8 run branch at 8c5324e. A mod's current release is mods/<game>/<mod>.json and another release is mods/<game>/<mod>@<version>.json, with the same validation as before. games/<game>/ holds only module.json and module.lua. In main and in signed catalogs the user trusts for modules, any other entry under games/ is refused. In every other bucket Modn ignores games/ at sync and refuses its modules at use. The folder boundary replaces the file-name scans, so a mod with the id module can be published. Package records use schema_version 2 with blake3, an ordered non-empty sources list, an optional redistributable flag (default false) and optional upstream_sha256. bucket.json uses schema_version 2, and Modn refuses version 1 with no compatibility layer. The buckets/main submodule stays on contract v1 until a maintainer republishes it.
