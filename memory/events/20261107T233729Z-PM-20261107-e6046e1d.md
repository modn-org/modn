Decided 2026-11-07: bucket contract v2 (#117) allows several sources per package. In the main bucket, sources list only origins that the mod's author publishes. modn-org hosts no copies of other people's archives, so 'Modn does not mirror these archives' (docs/buckets.md at 794cd8d) stays true.

Rejected: modn-org also mirrors archives marked redistributable. That improves availability, but modn-org would then redistribute other people's work and pay for storage.
