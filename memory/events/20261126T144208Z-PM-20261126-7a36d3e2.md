Observed 2026-11-26 at e7aa095 (Milestone 13). The official `main` bucket copy lives on the shared data directory, `ManagerRoots::official_main()` (`crates/modn-core/src/manager_roots.rs:119@e7aa095`). `BucketStore::new(roots: &ManagerRoots)` (`crates/modn-core/src/buckets/store.rs:105@e7aa095`) now takes the explicit roots value: it keeps bucket registrations on the manager profile, and `official()` reads `roots.official_main()` (`store.rs:239@e7aa095`). Registrations, module state and caches follow the `--state-dir` profile. The write path of the official copy, `update_main`, must also use the shared data directory; see PM-20261126-8676fc8f. The earlier warning that `BucketStore::new(root)` ignores its root is obsolete: the old thread-local `data_directory()` that it relied on was removed.
