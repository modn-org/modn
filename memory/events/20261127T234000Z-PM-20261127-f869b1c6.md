ensure_undo_target refuses history operations of kind profile_switch with UNDO_CONFLICT. A switch needs the verified archive cache and a fresh drift check, so undo cannot replay it safely; the user runs modn profile switch back instead. profile enable, disable, priority and apply record no history entry.
