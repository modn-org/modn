Decided 2026-11-26: keep the explicit ManagerRoots value resolved once per command (no thread-local DATA_DIRECTORY/PROFILE_DIRECTORY/MODULE_SOURCE, single ManagerRoots::write_targets check), as shipped in Milestone 13 at e7aa095. However, --state-dir is intended as a 100% isolated root (primarily for testing/sandboxing, especially once Milestone 20 ships in-app Profiles), so the official main bucket copy should live inside --state-dir rather than on the shared data directory. Tracked as low-priority follow-up issue #226. Until #226 lands, the current code at e7aa095 still stores the official main copy in the shared data directory.
