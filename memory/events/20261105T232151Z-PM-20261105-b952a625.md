As of 2026-11-05 (4e131b0), .gitignore ignores *.sqlite, so a committed state fixture such as a schema v2 database for migration tests must be added with git add -f. Read-only opens of v1 and v2 state use TEMP views (attach_legacy_views in state/roots.rs) so they can be read without migrating.
