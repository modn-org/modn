On 2026-11-09 the owner approved this bucket and theme design. Every bucket kind can contain themes in themes/<game-id>/<theme-id>/. Themes need no trust step, because they cannot run code: CSS only, an allowlist, a strict CSP, native destructive confirmations and protected install-review regions. Selecting a theme is the consent. A broken theme never blocks bucket or install operations. Local themes use modn theme register with no --trust flag. Bucket contract v2 (#117) moves package manifests to mods/<game-id>/ and keeps only game modules in games/<game-id>/. Correction: the earlier record said only main may contain games/. That contradicts PM-20261108-126126f3. main and the signed Git catalogs that the user trusts for modules may contain games/. Modn ignores games/ in other buckets at sync and refuses their modules at use. At 530b71e, read_packages rejects any non-JSON entry in games/<game-id>/, and a mod with the ID module collides with module.json. The owner stated that backward compatibility is not a concern, because Modn has no users.
