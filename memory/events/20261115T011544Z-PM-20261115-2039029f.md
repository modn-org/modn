On 2026-11-15 the approval journey of the desktop verifier found that the CLI content-root preview ignores --allow-executable, so the app's Allow button cannot unblock a tools/*.exe install for a content-root game. The verifier covers the executable ask on a tools-game fixture instead. Native-code approvals work for every game kind. The owner decides whether to change the CLI (issue 152 requires an executable mod to ask once per mod).
