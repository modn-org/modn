title: Pack publishers, not Modn, are responsible for redistribution rights
created_at: 2026-11-07T21:35:55Z
source: https://github.com/modn-org/modn/issues/113
---

On 2026-11-07 the user said Modn must not vet redistribution permissions when a pack is published. The user who publishes is responsible for proving the right to redistribute; GitHub's DMCA process handles disputes. Modn uploads every file the user includes and refuses nothing for licensing reasons. Modn asks once for an acknowledgement (skipped with --yes) and records each uploaded file's origin (source URL, author, package ID) for attribution. A per-package redistribute field was considered and dropped.
