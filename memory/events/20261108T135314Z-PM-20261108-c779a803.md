Owner preference, 2026-11-08: a project memory record that does not ship with a code or docs change is committed and pushed directly to main of modn-org/modn. Do not open a pull request for it. main has no branch protection, so a fast-forward push works. A record that describes a code change still lands in the same commit or pull request as that change, as AGENTS.md requires. PR #138, which carried only the Milestone 5 decision record, was closed for this reason and its commit pushed to main instead.
