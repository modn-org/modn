On a real Steam Cyberpunk 2077 installation (game 3.0.88.46235), the 11-package prerequisite stack installed through `modn install` in four user-authorized checkpoints. The user launched the game after each checkpoint and reported success. `modn uninstall` removed all 11 packages (137 owned files) in reverse order. The game tree then matched the preflight manifest except for runtime files the game created.

Checkpoints: a red4ext 1.31.0 + cet 1.38.1; b redscript 0.5.32 + codeware 1.21.2; c virtual-atelier 1.6.4 with archivexl 1.28.6 and mod-settings 0.2.28; d equipment-ex 1.2.10 with tweakxl 1.12.0, then browser-extension 0.9.7, then no-intro-videos 0.8. Limits: the backup was a SHA-256 manifest only, so Steam verification is the only restore path. The c and d launch reports were general, with no specific in-game feature checks. Residue the user chose to keep: 21 runtime files, 7 folders, a rewritten redscript_rCURRENT.log, and 4 older redscript logs removed by redscript's rotation. The run's three Modn gaps were fixed in PRs #45 and #46. The raw manifests and diffs are outside the repository, in the user's local modn-live folder.
