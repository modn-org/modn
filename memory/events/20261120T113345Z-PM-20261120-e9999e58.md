Package validation refuses a record whose sources mix Git and archive kinds, because one BLAKE3 pin cannot cover a packed Git archive. Every archive source of a release shares that one pin. For an archive release, the identity of any listed source therefore equals the identity of the primary source. Only the Git fallback case needs a listed-source commit, and round 5 covers it with the test a_fallback_install_from_the_second_git_source_is_current. The orchestrator rejected a round 6 archive identity change as dead code. This was true at commit 91f80d4.
