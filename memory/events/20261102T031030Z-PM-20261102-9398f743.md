The milestone 4 live run found that `list` hid the created-directory ledger and that catalog dry runs could not plan files for uncached `https` archives. Modn now prints the per-game created folders in `modn list` text and reports them as `created_directories` in `doctor --json`. `list --json` stays an array of packages. `install --dry-run --download` fetches missing `https` archives into the verified cache; a dry run still never downloads by default and never writes the game.

Created folders belong to a game installation, not to one package, so they are not added to each package's `directories` (exclusive folders only). Keeping `list --json` as an array avoids breaking consumers. `--download` is opt-in because a dry run must have no network or cache side effect unless the user asks; it validates that the cache is outside every game before downloading and is rejected without `--dry-run` or for standalone archives.
