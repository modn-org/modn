The current release stays games/<game>/<mod>.json and drives search, dependency resolution and install. Optional <mod>@<version>.json files add other releases that only modn update --version selects.

Chosen for issue #48 (choosing between several catalog releases of one mod) as a backward-compatible extension of bucket contract v1. The file-name version must equal the manifest version, a current release must exist, and each version appears once. Older Modn versions reject such files instead of misreading them. The bundled main snapshot has current releases only. Not done: install --version, and bucket show of other releases.
