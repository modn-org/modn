On 2026-11-14 Windows Defender detected the tiny Rust game stub that the Tauri desktop verifier compiled as Trojan:Win32/Bearfoos.A!ml (a machine-learning false positive, ThreatID 2147731250) and quarantined it. Reads of the file then failed with Errno 22 (Windows error 225) and journeys failed at random. The verifier now compiles nothing. Each fixture game executable is a byte copy of a signed Windows binary; the play journey starts a copy of mstsc.exe, which briefly shows a Remote Desktop Connection window, and stops only that process id. Never add a Defender exclusion to work around a detection.
