True at f537994 (2026-11-08): minisign-verify 0.3.0 does not expose a public key's or signature's key ID. Modn decodes it itself: the key ID is bytes 2..10 of the decoded minisign key or signature, read as a little-endian u64 and shown as {:016X}, which matches what the minisign CLI prints. Callers that pin or compare signer keys (Git catalog pinning, main release verification) must use CatalogKeyId from this function, not their own decoding.
