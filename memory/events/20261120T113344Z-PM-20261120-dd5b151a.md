Git reports a silent HTTP fetch as: fatal: unable to access the URL: Operation too slow. Less than 1 bytes/sec transferred the last N seconds. The message was verified against a local listening socket at commit ddcb44a. The setting http.lowSpeedTime takes whole seconds, so a test seam that shortens it rounds milliseconds up to one second. The low-speed limits bound HTTP and HTTPS transports only. Modn runs Git with LC_ALL=C so the message stays in English.
