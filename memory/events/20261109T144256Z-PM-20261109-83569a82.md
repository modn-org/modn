Decided 2026-11-09 by the Milestone 5 orchestrator run, after a blocking review finding (merged in a844f8a). At 530b71e docs/data-model.md said the module registry was independent of --state-dir, while bucket registrations already lived in the --state-dir profile. Milestone 5 tied module trust to bucket registrations, so a --state-dir run wrote trust in its profile but imported releases into the default registry and then refused them. Now the profile directory (the parent of state.sqlite) holds the module registry and bucket trust records; without --state-dir it is the runtime data directory. The official main bucket still comes from the data directory for every profile. No migration is needed because unversioned registry entries must be registered again anyway (PM-20261108-126126f3). The owner may revisit this choice.
