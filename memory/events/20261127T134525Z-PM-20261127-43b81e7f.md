Milestone 20 raises the state schema once, 7 to 8, with no migration: Store::open refuses every earlier user_version before it reads a table. managed_files stays the table of active on-disk winners and gains profile_id and archive_entry (NOT NULL DEFAULT '' so existing INSERT statements still work; profile code must write real values). file_claims holds every claim, winner and shadowed, for #206. profiles has UNIQUE (game_path, name) and a partial unique index that allows one active profile per game_path; profile_packages has UNIQUE (profile_id, priority). Foreign keys stay off, so Modn deletes memberships explicitly. #124 needed no schema change.
