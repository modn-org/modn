As of 2026-11-13 with FigCraft 0.17.0 headless: a Card instance exposes only title and body, so a card with two buttons is a Card-styled frame. component.exposeInstance succeeds but declares no parent property, so nested badge and Button settings need variants (mod-tile state). Hug instances ignore a fixed main-component height, so set the instance height. Run component.properties on a set before planning a screen: the Library task blocked once because mod-tile and tabs lacked properties. audit.py flags every unbound fill, so review-only colours must be variables, and the Primary candidates swatches sit in a fourth collection named candidates.
