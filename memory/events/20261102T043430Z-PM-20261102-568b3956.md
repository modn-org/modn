All Rust, Lua, Python and TOML comments were removed except keeps. modn-core keeps doc comments on public items that state a contract. Docs that only restate an item name were replaced by #[expect(missing_docs, reason = ...)] on the parent struct, enum or impl.

Keeps: platform and dependency gotchas (NTFS case folding, 8.3 names, MoveFileEx, inode reuse, Windows verbatim paths, 7z solid blocks, ZipWriter duplicate names) and the clap help doc comments in apps/modn-cli/src/commands.rs, which are help text. crates/modn-core/src/lib.rs keeps #![warn(missing_docs)] and CI runs clippy with -D warnings, so public items need a doc or an expect. Claimed constraints that lost their comment: the 7z header bound (capabilities.rs, covered by tests/read_only_capabilities.rs) and the Lua proxy rawset caveat (runtime.rs, not enforced).
