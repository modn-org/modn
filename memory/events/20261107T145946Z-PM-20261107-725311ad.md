The Balatro packages use native_injector and the git source kind, and the Balatro module uses API 2. Modn 0.3.0 deserializes package manifests with deny_unknown_fields and knows no git source, so a 0.3.0 client will probably fail bucket update once main ships these files. Not run against 0.3.0. Merge the modn-org/main Balatro PR only after a Modn release that carries API 2, then point .github/modn-ref and min_modn_version at that release.
