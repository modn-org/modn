On 2026-11-26 the owner decided to isolate the install review and approval prompts into a single dedicated protected modal outside .modn-main, .modn-view, .modn-details and .modn-library, with simple color, font and layout theming. Once issue #220 ships, those layout ancestors leave PROTECTED_CONTEXT_CLASSES so themes can style .modn-main layout again, and overlay.rs rules will be re-evaluated for the isolated modal layer. Until #220 lands, the current code at 66e8735308c still enforces the static overlay checker and ancestor restrictions from PM-20261124-b7e41a02.
