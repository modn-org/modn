On dev, acknowledged adoption verifies selected file sizes and digests, then records individual ownership atomically without game writes or directory claims. Approved cleanup removes recorded targets only. It retains dependency checks, identity checks, current-byte backups and recovery. Ordinary uninstall remains strict. CLI wiring requires its own proof.
