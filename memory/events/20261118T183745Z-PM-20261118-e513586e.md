Decided 2026-11-18 in the PR 185 review fixes (merged as ae37c31). The install and update history record names the source that supplied the archive, not the first source in the release list, so undo looks for the cached archive under that source. A user-supplied --file archive is recorded as a manual source, and undo returns UNDO_SOURCE_MANUAL because Modn has no URL to fetch again. A release whose first source is manual but whose archive came from a later fetchable source still restores from that source. Test fixtures that need an undoable install seed the archive cache first and install without --file. docs/history.md and docs/sources.md state the rule.
