First-party game modules live beside mod manifests in the official main bucket. Modn embeds no modules or bucket manifests. First use bootstraps a verified local copy, and explicit bucket update refreshes it atomically. Only main may contain modules; third-party modules and Git-backed catalog sync remain deferred.

The layout is buckets/main/games/<game-id>/module.json and module.lua beside package manifests. Bootstrap downloads the running version release ZIP, verifies its built-in tree digest, validates it, and installs it atomically. MODN_MAIN_BUCKET_SOURCE permits an HTTPS URL or local ZIP without bypassing the digest. Explicit update downloads the latest release ZIP and SHA-256 sidecar over HTTPS, validates them and swaps atomically; failure preserves the prior copy. Registered local buckets reject module files and all buckets reject modules/ directories.
