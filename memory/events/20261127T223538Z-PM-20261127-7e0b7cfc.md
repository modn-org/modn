While verifying the Unix branch under WSL Ubuntu 26.04, the failed-exit tree test hit ETXTBSY (text file busy) because another thread held a write handle to a stub script while it was executed. Commit 5e574ef added a retry in acquisition/git/run.rs. The pack init path has no such retry; ten acquisition runs passed. rustix 1.1 names ESRCH Errno::SRCH. A CI flake in the stub-based Git tests on Linux may come from this.
