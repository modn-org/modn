On 2026-11-07 the user said they test the Nexus Mods provider (issue #57) with a free Nexus account. The Nexus API returns a download link for an API key alone only to Premium accounts. A free account must also pass the key and expires values from an nxm:// link that the Nexus website opens. The provider must therefore accept an nxm:// link for each download, and must also work with Premium by API key alone.
