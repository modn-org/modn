A survey of ~/Downloads/CP77 found 12 mods with GitHub repos; 8 were already in main. Input Loader 0.2.6 and BetterLootMarkers 1.4.1 were added as https GitHub release sources. Let There Be Flight 0.3.20 was not added: its ZIP ships red4ext/plugins/let_there_be_flight_uninstall.bat, which the Cyberpunk policy blocks (EXECUTABLE_PAYLOAD, UNRECOGNIZED_LAYOUT).

SHA-256 of both GitHub assets matched the digest GitHub publishes, and the Input Loader and Let There Be Flight Nexus files are byte-identical to the GitHub assets. The ignored real-stack gate (milestone_gate, MODN_GATE_ARCHIVES) installed all 13 packages in a disposable fixture, uninstalled them and restored the tree: 147 owned files (137 for the original eleven). Not exercised on a live game installation. Native Settings UI has a GitHub repo (justarandomguyintheinternet/CP77_nativeSettings) but no GitHub release asset, so it was not added. Allowing the .bat would be a policy decision for the owner.
