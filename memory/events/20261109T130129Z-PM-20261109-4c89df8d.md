Observed 2026-11-09 during Milestone 5 (T2b, commit dc628d6). A BucketStore built from a bucket-store root must not resolve the official main bucket or the game-module registry from that root; both come from the Modn data directory. Moving official() to the store root broke apps/modn-cli/src/catalog_snapshot_tests.rs. Code that imports or resolves modules from a store must take the data directory explicitly.
