Decided 2026-11-07, not implemented at 794cd8d: #90 signs main releases and community catalogs with Ed25519 over a canonical BLAKE3 digest of the catalog contents, not over a Git commit.

Rationale: the same signature then works over Git, a catalog ZIP over HTTPS (#119), relocation (#120) and lookup by key (#125). Git SSH signatures work only for Git.

Each community catalog pins its signer key at first sync, and Modn shows the fingerprint. The main signer key ships with the installer, and its signature replaces the main-bucket.zip.sha256 sidecar. Key rotation and revocation are #122.
