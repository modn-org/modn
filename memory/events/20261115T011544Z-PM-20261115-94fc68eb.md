On 2026-11-15 the end-of-run review of the desktop verifier found that a plain cargo build of modn-cli compiles the two test overrides out. A verifier run with such a binary would read the real Steam library and install into the real game mod folder, for example %APPDATA%\Balatro\Mods. The verifier now searches the CLI binary for both names and exits with status 2 before any journey runs when one is missing. A release modn.exe has no overrides, so release verification needs a verifier CLI built from the release tag with --features modn-core/test-instruction-budget.
