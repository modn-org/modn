On 2026-11-20 the engine accepted `:root{--modn-font-size-body-s:0}`, `:root{--modn-font-line-body-s:0}`, `:root{--modn-space-4xl:0}` and `:root{--modn-opacity-disabled:0}`. Protected rules read these tokens, so a theme can shrink or hide protected text and a disabled protected button. `docs/desktop.md` says a theme may change colours and fonts only. The ignored test `known_gap_root_tokens_can_shrink_protected_content` records the gap. The owner has not decided between constraining the token values in the engine and giving protected CSS non-themable values.
