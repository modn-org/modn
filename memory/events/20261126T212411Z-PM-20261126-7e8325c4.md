As of bf3a78d (2026-11-26), after Milestone 13 (ManagerRoots), the module registry, bucket store and archive cache follow --state-dir, while the official main bucket copy still derives from LOCALAPPDATA (until issue #226 lands) and content-root resolution reads APPDATA / MODN_APPDATA. CLI tests and library entry points that resolve app data must redirect LOCALAPPDATA, APPDATA and MODN_APPDATA to a temporary directory so they never touch the user's real Modn state.
