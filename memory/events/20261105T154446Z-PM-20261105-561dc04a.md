Project memory is one immutable Markdown record per decision or finding under `memory/events/`, managed with the `project-wiki` skill (sooskca/skills#94). Parallel PRs add different files, so GitHub merges never conflict; GitHub ignores the `merge=union` driver that `memory/events.jsonl` relied on (modn-org/modn#86), and local union merges had reordered records (modn-org/modn#82).

On 2026-11-05 the 48 records of `memory/events.jsonl` were converted one to one into record files, with every ID, kind, title, timestamp, confidence, source, relation, tag and supersession kept; summary, body and supersession reason form the new body. `claim_class`, `valid_from` (equal to `created_at` in every record), `status` and `operation` were dropped because they are derived or constant. The log, `memory/CURRENT_STATE.md`, the `merge=union` rule, the project-memory ignore rules and the `project_memory` MCP server in `.codex/config.toml` were removed. Records are ordered by `created_at`, then `id`, not by merge order.
