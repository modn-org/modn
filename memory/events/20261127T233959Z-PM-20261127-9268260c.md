Milestone 20 lets two managed mods claim one file path; the newest install wins and the other keeps a shadowed claim. Conflicts a mod manifest declares are a different case: Store::conflicting_packages and the catalog pipeline still refuse them before any install, and priority never overrides them. Chosen so a mod author's explicit conflict statement keeps its meaning. Recorded at 4f2c1e4.
