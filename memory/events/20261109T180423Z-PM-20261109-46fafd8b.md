On 2026-11-09 the owner set these desktop principles, and revised the detection and undo placement the same day. Everyday operations take one click: install, update, uninstall, undo and play. Modn proves safety with its own checks, transactions and undo, not with a plan that the user reads. A blocked plan shows its reason and asks nothing. A native-injector or executable mod asks once per mod, and again when a new release adds native code. Adoption and forced cleanup keep explicit confirmation. Undo of an uninstall downloads the archive again when it is not cached; a manual source cannot. The app detects supported games at every launch and shows each detected, unregistered game in grayscale; clicking a game activates it, which registers it and writes manager state only (#150 as edited on 2026-11-09). Undo appears in a toast after each operation, in the History section of the mod details page, and in the game library's Recent menu; there is no History page (#149 as edited on 2026-11-09). The app never shows CLI output; the install button shows progress and becomes Cancel, which is safe only before the commit. Steam Workshop is the interaction inspiration, without its look or names. A collection is a curated bucket list that resolves to current releases; a pack is a user lockfile with exact pins; they stay separate and share the stack install path. Only main collections may trigger the one-time Essentials suggestion on a game's first install. Milestone 6 was split into Desktop foundation and MCP (6) and Desktop catalog and collections (12).
