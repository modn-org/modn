On 2026-11-24 the human chose an explicit no-theme selection. Before, 'Use default theme' cleared the selection, so the official theme of the game applied again and the choice did nothing. Now modn theme select <game> --none stores a record with theme null (schema_version stays 1). Resolve returns theme null and fallback null for it and skips the official theme. List marks no theme selected. modn theme reset still clears the selection, so the official theme applies again. The desktop button calls select_theme with a null theme (e2431fa).
