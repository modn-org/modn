On 2026-11-24 the CLI content-root install preview stopped dropping the explicit executable approval. Before, install.rs called preview_install_zip_with_appdata and ignored args.allow_executable, so the preview kept the blocker EXECUTABLE_PAYLOAD. Now the preview, the catalog install preview and the stack install preview pass the approvals. Two tests in content_root_executable_cli.rs cover a missing or wrong path (still blocked) and a matching path (preview reviewable, install writes into the content root, not the game root). Journey 12 approval-content-root of the desktop verifier covers the executable ask on the content-root Balatro fixture; journeys 7 and 12 passed with 159 assertions on 771ce05. Approval matching compares the destination string only and ignores the root (crates/modn-core/src/planning.rs:105). The preview still reports the root, so no input authorizes an executable outside what the preview shows. The catalog and stack previews have no content-root test.
