On dev, the stdio companion fixes its backend, manager state and allowed input roots at startup. Typed requests use literal arguments. Writes require server opt-in and request approval. Framing, output and execution are bounded. Canonical path checks do not prevent concurrent external path replacement. Empty argument objects require explicit object validation before Serde decoding.
