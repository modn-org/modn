On 2026-11-20 the test `a_missing_assets_dir_is_refused` failed with AlreadyExists. Its helper `unique_folder` named a folder with the process id and a counter and the test never removed it. Windows reuses process ids, so a later run met the old folder. The helper now removes a stale folder first, and the test removes its own folder. A test that creates a temp folder should create it through a self-cleaning helper.
