Found 2026-11-14 while planning Milestone 8. Python has no BLAKE3 in its standard library and the repository scripts use only the standard library. The rehash script for the main bucket (issue #123) therefore calls modn catalog hash from issue #121 for the BLAKE3 pin, and verifies the current SHA-256 pin with hashlib. The script lives in modn-org/modn, not in the buckets/main submodule, because a commit to modn-org/main is a maintainer action. The real rehash, the main provenance note and the main release remain maintainer work.
