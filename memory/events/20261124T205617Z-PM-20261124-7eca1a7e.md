On 2026-11-24 Modn v0.7.0 and the signed main bucket release v2026.11.24 shipped together. The bucket moved to contract v2: records under mods/<game-id>/ with BLAKE3 pins, upstream_sha256 provenance and sources lists, and both game modules declare host API 3. The 22 former manual Cyberpunk 2077 records now have one nexus source each; each local archive was matched to its Nexus file by MD5 through the Nexus API, and its SHA-256 matched the v1 pin. cyberarms-patch now says version 1.5, the Nexus label of that file. The bucket ships the official Night City theme and its CI runs `modn theme check`.

Issues #117, #123 and #147 are closed, and so is the Game themes milestone. Durable distribution keeps #124 open.

The CLI tests now read the v2 submodule directly; the to_contract_v2 test helpers were removed.

Finding: Modn 0.6.0 refuses the v2 bucket, and `modn bucket update` always takes the latest main release, so 0.6.0 installs could not update main between the two releases. Issue #210 proposes choosing the newest supported release; #209 asks for a written versioning rule. modn-org/main#10 raises min_modn_version to 0.7.0 in both modules.
