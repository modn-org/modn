Pull-request validation never reads the secrets: it signs a copy with an ephemeral key from the sign_catalog example and runs a test-main-key modn build. The release has no .sha256 sidecar, so Modn 0.4.0 bucket update fails against it until the Milestone 4 Modn ships. modn-ref pins 5004723; pin a Modn release there after it ships.
