modn-cli enables the modn-core feature test-instruction-budget only as a dev-dependency. Cargo resolver 2 unifies it into the binaries that CLI integration tests spawn, so test-only overrides such as MODN_APPDATA, MODN_TEST_UPDATE_FAULT_AFTER and the git file:// remote base work in those child processes. A normal cargo build of modn-cli has none of them; the run-branch review confirmed this with cargo tree on normal edges.
