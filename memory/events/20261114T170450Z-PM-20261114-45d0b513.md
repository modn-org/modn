Decided 2026-11-14 while moving archive pins to BLAKE3. A cancelled undo changed .digest-index.json in the cache and broke the guarantee that a cancelled operation writes nothing. Now only storing a downloaded entry writes the digest index. A read rebuilds a missing or sha256 index in memory and persists nothing. The cost is that alias lookups scan the cache each time until a download writes the index.
