A package's exclusive directories (managed_directories rows) belong to the installation, not to one profile. Test profile_switch_keeps_managed_directories keeps the row across a switch. Known side effect: a switch creates a missing parent directory for a written file, and a rollback leaves that empty directory. Recorded at 4f2c1e4.
