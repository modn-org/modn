The verify-ownership skill checks path containment, documented Windows names, ownership-key coherence and CLI dry-run/install/uninstall exactness with proptest on the real code, using the live file system and Microsoft's naming rules as oracles. Kani was not used because it does not run on Windows hosts and cannot model the file system, SQLite or Lua. Properties that fail on known findings are #[ignore] in cargo test and run with --include-ignored.
