On 2026-11-20 the desktop half exists and the CLI half does not. A refused `modn theme register` must print `{"error":"THEME_INVALID","message":text,"diagnostics":[diagnostic...]}` on stderr with exit status 1 in `--json` mode. The desktop keeps diagnostics only for that code. It keeps at most 50 entries with the keys theme, path, line, rule and message. It cuts message at 300 characters and theme at 130, removes control characters and nulls an absolute, `..` or over-long path. The CLI task that follows PR #185 must emit this envelope.
