Decided 2026-11-26 for Milestone 13 "Manager roots" (issues #158, #159, #160, #161), shipped at e7aa095. Manager locations are one explicit `ManagerRoots` value (`crates/modn-core/src/manager_roots.rs`): shared data directory, manager profile selected by `--state-dir` (the data directory when none), archive cache, and an optional development module directory. The CLI resolves it once per command (`ManagerRoots::from_environment`, `manager_roots.rs:48@e7aa095`) and passes it to the bucket store, module registry, resolver, visibility, inventory, import, detection, scan and launch. The thread-local `DATA_DIRECTORY`, `PROFILE_DIRECTORY` and `MODULE_SOURCE`, `data_dir.rs`, `with_data_directory`, `with_profile_directory` and `with_module_source` are deleted. The official `main` copy follows the data directory; everything else follows the profile. `ManagerRoots::development_modules` is a direct module directory; `MODN_GAME_MODULES_DIR` stays a process environment base that the resolver joins with the game id (`crates/modn-core/src/game_modules/resolver.rs:32@e7aa095`). `ManagerRoots::write_targets` (`manager_roots.rs:101@e7aa095`) is the single list of manager write locations and `validate_write_targets` (`apps/modn-cli/src/state_access.rs:212@e7aa095`) the single check. Tests may migrate their setup to the roots value; no assertion may be deleted or loosened, and `apps/modn-cli/tests/module_state_dir_cli.rs` stays unchanged. The environment lookup (`LOCALAPPDATA`, `XDG_STATE_HOME`, `HOME`) lives in the private `default_data_directory` (`manager_roots.rs:131@e7aa095`).
