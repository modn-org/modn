Only the archive cache deduplicates, by pinned SHA-256 with byte re-verification. Modn never shares installed game files between packages.

Issue #56 asked for deduplication of archives and files. PR #81 (merged on 2026-11-05) shipped verified archive reuse across packages and source aliases. Hard links or shared copies of installed files would let a change through one package alter another package's files. Modn could then no longer detect drift, roll back or uninstall one package without touching the other. `docs/cache.md` stated on 2026-11-05 that Modn never deduplicates mutable game files.

This replaces record `PM-20261105-71a02f6f` from PR #99, which was written to the removed `memory/events.jsonl`.
