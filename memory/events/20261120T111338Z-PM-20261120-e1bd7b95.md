On 2026-11-20 the end-of-run review of Milestone 11 found that a theme could set `:root{--modn-color-text:rgba(0,0,0,0)}` or `:root{color:transparent}`. The install review and the approval ask read those values, so their text became transparent while the Allow button stayed visible. The core rule engine now requires an opaque colour for every `--modn-color-*` custom property on any selector and for `color` on `:root` and `html`. It reuses the rule id `protected-color-not-opaque`. Shared hooks may still use translucent colours through their own properties.
