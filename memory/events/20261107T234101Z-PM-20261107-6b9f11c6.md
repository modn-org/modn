On 2026-11-07 the owner approved Milestone 7 'Modpacks and sharing' and later moved its pins to BLAKE3. A pack is a lockfile: the game, each package with bucket, version and BLAKE3 pin (bucket contract v2, #117), and config files. Import treats a pack as untrusted input, verifies every BLAKE3 pin and installs transactionally. A pack may carry game modules once module trust by bucket (#93) and module pins (#92) exist; import then requires the #93 trust acknowledgement and official main modules keep priority. Packs publish to GitHub releases and import by github:<owner>/<repo>@<tag> with a pinned signer, as for catalogs (#90). Peer-to-peer sharing uses iroh, chosen over BitTorrent, Magic Wormhole, Syncthing and IPFS because it is a Rust library with NAT traversal and verified streaming. Milestone 7 depends on Milestone 6 only for the desktop issue #116.
