On 2026-11-09 the owner approved this bucket and theme design. Every bucket kind can contain themes in themes/<game-id>/<theme-id>/. Themes need no trust step, because they cannot run code: CSS only, an allowlist, a strict CSP, native destructive confirmations and protected install-review regions. Selecting a theme is the consent. A broken theme never blocks bucket or install operations. Local themes use modn theme register with no --trust flag. Bucket contract v2 (#117) also moves package manifests to mods/<game-id>/ and keeps only game modules in games/<game-id>/. Only main may contain games/. At 530b71e, read_packages rejects any non-JSON entry in games/<game-id>/, and a mod with the ID module collides with module.json. The owner stated that backward compatibility is not a concern, because Modn has no users.
