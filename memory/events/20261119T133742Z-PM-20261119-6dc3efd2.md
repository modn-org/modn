The Windows CI test a_stalled_fetch_ends_the_grandchild_before_it_returns failed because its stub waited silently for a PowerShell grandchild to write a pid file. The 3000 ms inactivity limit ended the fetch before PowerShell started. The fix makes the stub print progress until its pid exists and checks a heartbeat file for the end of the tree, so no assert depends on start speed.
