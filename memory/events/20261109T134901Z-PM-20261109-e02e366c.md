On 2026-11-09 the owner chose Tauri 2 for the Windows desktop app. The reason is full CSS theming: themes must control layout, sizing, fonts and colors through one CSS file. GPUI Kit 0.9.0 has no stylesheets, selectors or cascade. A CSS engine on GPUI would be a permanent custom subset. The owner said the GPUI Kit choice was made on a whim and that the GPUI app was a disposable single-prompt result. The port keeps backend.rs and its contract tests, uses plain HTML, CSS and ES-module JavaScript with no bundler, and enables only fixed commands with a strict CSP. Destructive confirmations use native dialogs. BUI was rejected for GPL-3.0 and no accessibility. egui was rejected for its weak styling model. Raw wry was rejected because Tauri already provides IPC, capability limits, CSP and packaging. #142 tracks the port. Milestone 11 (Game themes) depends on it.
