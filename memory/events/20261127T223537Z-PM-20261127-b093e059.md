The task for issue 190 checked git help --config on Git 2.56 and found no http.connectTimeout setting. A TLS handshake that stalls after TCP connects therefore ends only at the Modn hard deadline of 15 minutes, and docs/sources.md says so. The sentence that the OS TCP timeout bounds the Git connection was removed. Verified on 2026-11-27 at commit f1d151a.
