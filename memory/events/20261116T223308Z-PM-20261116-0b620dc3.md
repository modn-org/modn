On 2026-11-14 Windows Defender detected the tiny Rust game stub that the Tauri desktop verifier compiled as Trojan:Win32/Bearfoos.A!ml (a machine-learning false positive, ThreatID 2147731250) and quarantined it. Reads of the file then failed with Errno 22 (Windows error 225) and journeys failed at random. The verifier now compiles nothing. Each fixture game executable is a byte copy of a signed Windows binary. A renamed copy of mstsc.exe, used first for the play journey, has no language resource file (Balatro.exe.MUI) and showed a file-not-found dialog on the user's desktop, which took the focus. The play fixture is now systeminfo.exe, a console program: the hidden console of modn play gives it no window, and the journey fails when a visible window of the fixture image appears. A game fixture must be a signed console binary that stays alive for a few seconds with no arguments, null stdio and the small environment that the app forwards. driverquery.exe lives 8 s with a full environment but under 1 s with that environment. Never add a Defender exclusion to work around a detection.
