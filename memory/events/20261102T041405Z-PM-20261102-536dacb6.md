The Release workflow builds modn.exe with RUSTFLAGS=-C target-feature=+crt-static, and the smoke test rejects any Visual C++ runtime DLL import.

Measured on 2026-11-02 with stable Rust on x86_64-pc-windows-msvc: a default release build imports VCRUNTIME140.dll and eleven api-ms-win-crt-*-l1-1-0.dll files. A +crt-static build imports none of them. GitHub windows-latest runners have the Visual C++ Redistributable, so a runner smoke test alone cannot detect this dependency. The smoke test therefore searches the binary for C runtime DLL import names. Issue #47.
