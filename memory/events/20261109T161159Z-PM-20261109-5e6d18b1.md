On 2026-11-09 the owner replaced one design file per page with a single file, design/design.figcraft, that holds one page per desktop screen. The owner owns its design system: the variables, the text styles, and the Foundations and Components pages. The agent edits screen pages on request and changes the design system only when the owner asks in that conversation. Variables and components are local to the file, so no library publish, link or update step remains, and a design-system change reaches every screen at once. The agent still drives the owner's running FigCraft app through figcraft-cli mcp --attach, and still stops and asks when a request conflicts with the design system. Git can neither diff nor merge .figcraft files, so one branch at a time may change the file and the PNG renders are the reviewable change. The owner chose Manrope for the text styles on 2026-11-09; the styles take it from the modn/font/family variable. Tokens named modn/<group>/<name> export as var(--modn-<group>-<name>), matching the --modn-* theme properties of #142.
