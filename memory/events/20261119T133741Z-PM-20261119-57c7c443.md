The Git fetch runs in its own process group, so a terminal Ctrl-C reaches only Modn. Modn core keeps a registry of live fetch groups (pack/registry.rs). The CLI installs a signal-hook thread on Unix (interrupt.rs). On SIGINT or SIGTERM the thread kills every registered group, then exits with 128 plus the signal. The workspace forbids unsafe code, so a safe signal crate is the only handler route. A signal between spawn and registration stays uncovered.
