On 2026-11-20 `buckets/main` is a git submodule of the `modn-org/main` repository. Issue #147 asks that repository to publish `themes/cyberpunk-2077/<theme-id>/`. This repository stages the theme `night-city` in `examples/themes/cyberpunk-2077/night-city/` with a test that runs the real rule engine on it. Issue #147 stays open until the folder is copied to `modn-org/main` and its CI runs `modn theme check`.
