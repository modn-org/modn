Shipped in 3e5e697 (2026-11-27): `ManagerRoots::official_bucket_root()` returns `profile.join("buckets")` (`crates/modn-core/src/manager_roots.rs:129@3e5e697`), so the official `main` bucket copy lives inside `--state-dir` when one is selected. Without `--state-dir` the profile is the shared data directory, so the layout and behavior are unchanged. `BucketStore::official()` (`crates/modn-core/src/buckets/store.rs:220@3e5e697`) and `BucketStore::update_main` (`crates/modn-core/src/buckets/update.rs:136@3e5e697`) use that root; the theme catalog reads `roots.official_main()` (`apps/modn-cli/src/themes.rs:254@3e5e697`). `modn bucket update --state-dir <path>` writes `<path>/buckets/main` and writes nothing into `LOCALAPPDATA`. This supersedes the shared-`main` split recorded in PM-20261126-fd017206 and the intent recorded in PM-20261126-2791d745.
