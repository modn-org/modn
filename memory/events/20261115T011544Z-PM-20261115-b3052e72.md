On 2026-11-15 the official main bucket in the buckets/main submodule was still contract v1 (tag v2026.11.13), and the CLI at main 1773c2d refuses v1 buckets. The Tauri desktop verifier therefore generates its own v2 main bucket with a Balatro API 3 module in each fixture. A direct copy of a bucket under <data>/buckets/main loads as the trusted main without a signature. Catalog releases install offline: the helper writes the v2 manifests (mods/<game>/<id>.json and mods/<game>/<id>@<version>.json, BLAKE3 pins) and seeds the download cache entry, whose name uses the first seven hex characters of the BLAKE3 digest of the source URL. A repeated version is refused by the bucket store.
