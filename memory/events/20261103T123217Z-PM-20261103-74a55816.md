Microsoft's Naming Files rules reserve COM¹-COM³ and LPT¹-LPT³ in every directory. validated_name only rejects a 4-byte stem ending in an ASCII digit, so archive/pc/mod/COM¹.archive is accepted. On the Windows 11 test machine the name creates an ordinary file, so harm was not observed; it follows the documented rule only.
