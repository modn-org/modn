The Windows install script verifies modn.exe, installs it, and runs modn bucket update. Modn never fetches the main bucket implicitly or embeds its digest. Explicit updates verify the release ZIP against its same-origin SHA-256 sidecar; release signing and the separate modn-org/main repository are future work. Only main contains game modules.
