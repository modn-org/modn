On 2026-11-05 the maintainer chose Balatro as the second official game module for Milestone 3 (Real-game validation). It replaces Skyrim Special Edition, which the maintainer does not have installed, so a Skyrim real-install check could not run. The milestone exit gate and issue #52 now name Balatro.
