As of a1916a7 (2026-11-11), a change to a module's `stores` or `launch` data is a module release: `module.json` `version` must change and must equal the Lua `policy.version`. Modn 0.5.0 and earlier refuse `stores` and `launch` as unknown manifest fields. So the `main` bucket release that adds them, and `buckets/main/.github/modn-ref`, must ship only with or after the Modn release that reads them.
